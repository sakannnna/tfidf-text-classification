# MLP原始小批次损失补记

目的：展示每次小批次更新的真实损失起伏，不更换方案、不重新调参。

2026-10-11补跑单层100单元MLP，alpha=0.0001、ReLU、Adam、种子42、最多300轮；仍按训练损失改善情况停止。数据、清洗、TF-IDF、划分、打乱顺序及优化器设置保持原样。验证集仅评分，不参与训练或停止判断。

## 记录口径

- 5894条训练样本；默认batch_size=auto实际为200，每轮29批200条及1批94条。
- 共67轮、2010条原始批次损失。直接保存sklearn `_backprop`返回的原损失与批次大小，再原样返回损失和梯度，未重写优化器。
- 该损失为本批次预测交叉熵加L2惩罚，在当前批次权重更新前计算。尾批次大小不同，L2项也使用库原本的批次样本量归一化；波动不能全归因于样本难度，更不能单凭尖峰断言过拟合。
- 每轮的训练/验证交叉熵在轮末用同一模型计算，不含L2。两类损失含义不同，不直接比较数值。
- 未做移动平均、指数平滑、曲线拟合、删点或下采样；对数轴仅改变显示刻度，Matplotlib路径简化已关闭。

## 核验结果

- 原类与记录类在微型合成数据上：权重、预测概率、逐轮损失完全一致，包含尾批次校验。
- 2010条批次记录完整、有效；逐轮按批次样本量加权，与库的原训练目标一致。
- 与原逐轮实验相比，全部67轮的训练目标、训练/验证交叉熵、Accuracy及Macro-F1共7项指标完全一致。
- 与原MLP基线的训练目标轨迹相符，最终1474条验证预测完全一致。
- 最终验证Accuracy为94.4369%，Macro-F1为0.944588；验证交叉熵0.196442，最低点仍为第67轮。
- 这只是同配置的观测补跑，不是新增独立验证、随机种子重复或测试集成绩。没有改动已有最终模型或prediction.csv。
